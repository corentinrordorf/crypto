ℹ️ À propos d'AES-256-GCM

AES (Advanced Encryption Standard) est l'algorithme de chiffrement symétrique le plus utilisé au monde. La variante AES-256-GCM utilise une clé de 256 bits et offre :
  • Confidentialité : Seul celui qui possède la clé peut déchiffrer
  • Intégrité : GCM (Galois/Counter Mode) détecte toute modification des données
  • Performance : Très rapide, même pour de gros fichiers
  • Sécurité : Utilisé par les gouvernements et les banques

🛡️ Sécurité : Toutes les opérations sont effectuées localement dans votre navigateur. Aucune donnée n'est envoyée à un serveur.
